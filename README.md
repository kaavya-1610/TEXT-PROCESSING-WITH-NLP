# Text Processing and NLP Project

## Introduction
This project focuses on various techniques and methods used in text processing and Natural Language Processing (NLP). The objective is to demonstrate how to preprocess textual data, apply NLP algorithms, and evaluate the results.

## Installation
To get started with the project, you need to install the necessary dependencies. Use the following command:

```bash
pip install -r requirements.txt
```

## Usage
After installing the necessary packages, you can run the main script:

```bash
python main.py
```

## Features
- Text preprocessing (tokenization, stemming, and lemmatization)
- Sentiment analysis using various algorithms
- Named Entity Recognition (NER)
- Text classification
- Visualization of results

## Technologies Used
- Python
- NLTK
- SpaCy
- Scikit-learn
- Matplotlib
